# Smart Agriculture Gaza AI

مشروع لتصنيف حالة رطوبة التربة واتخاذ قرار تشغيل مضخة الري باستخدام شبكة عصبية، وواجهة ويب، وسيرفر Flask، وربط اختياري مع ESP32.

## التشغيل السريع على Windows

1. ثبّت Python 3.12 وتأكد من اختيار `Add Python to PATH` أثناء التثبيت.
2. فك ضغط المشروع.
3. شغّل الملف `run_local.bat` بالنقر المزدوج.
4. انتظر حتى تنتهي عملية تثبيت المكتبات.
5. افتح المتصفح على: `http://127.0.0.1:5000`
6. لا تغلق نافذة الأوامر أثناء استخدام الموقع.

ملفات النموذج المدرب موجودة مسبقًا. استخدم `retrain_model.bat` فقط عندما تريد إعادة تدريب النموذج من ملف `data.csv`.

## تشغيل يدوي

```bash
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
python train_model.py
python app.py
```

## اختبار السيرفر

- الواجهة: `http://127.0.0.1:5000`
- فحص السيرفر: `http://127.0.0.1:5000/health`

## النشر على Render

1. ارفع ملفات المشروع إلى مستودع GitHub.
2. أنشئ Web Service جديدًا على Render واربطه بالمستودع.
3. يمكن لـ Render قراءة `render.yaml`، أو استخدم يدويًا:
   - Build Command: `pip install -r requirements.txt && python train_model.py`
   - Start Command: `gunicorn app:app`
4. بعد النشر، انسخ رابط Render وضعه في حقل رابط السيرفر داخل الواجهة.
5. ضع الرابط نفسه مع المسار `/api/esp32` داخل `esp32_node.ino`.

كود ESP32 يحوّل قراءة ADC من المجال `0..4095` إلى المجال `0..480` المستخدم في بيانات التدريب. عند تركيب الحساس الحقيقي يجب تعديل حدود المعايرة حسب قراءته في التربة الجافة والرطبة.

## الملفات الرئيسية

- `data.csv`: البيانات الأصلية.
- `cleaned_data.csv`: البيانات بعد إزالة القراءات التالفة.
- `train_model.py`: تنظيف البيانات وتدريب النموذج وحفظ النتائج.
- `app.py`: واجهة Flask البرمجية.
- `index.html`: واجهة المستخدم.
- `esp32_node.ino`: كود ESP32.
- `model_metrics.json`: نتائج تقييم النموذج.
- `test_predictions.csv`: تنبؤات مجموعة الاختبار.

## ملاحظة عن البيانات

الكود يحذف تلقائيًا القراءات غير المنطقية، ولا يستخدم أعمدة `note` أو `status` في التدريب لتجنب تسريب النتيجة إلى النموذج.
